เปิดโปรแกรม
1. แนะนำให้ดับเบิลคลิก C:\E\HairTutorial\Run_Hair_Tutorial_Tool_Silent.vbs เพื่อเปิดโดยไม่มีหน้าต่าง Python/Command
2. ไฟล์ Run_Hair_Tutorial_Tool.cmd ยังใช้ได้สำหรับตรวจปัญหา แต่จะมีหน้าต่าง Command เปิดอยู่
3. ติ๊กเลือกแพลตฟอร์มได้หนึ่งหรือหลายรายการพร้อมกัน โปรแกรมเริ่มต้นโดยเลือกทั้งสามแพลตฟอร์ม
4. เมนูด้านบนแบ่งเป็น 3 แท็บ: Find & download, Edit & review, Music & StockOS
5. ตารางดาวน์โหลดอยู่ด้านล่างและเห็นได้ทุกแท็บ ขยายหน้าต่างเพื่อให้เห็นแถวเพิ่ม หรือกด FULL QUEUE เพื่อดูเต็มหน้าต่าง

โหมดอัตโนมัติ (แนะนำ)
1. ใส่หัวข้อในช่อง Topic / keywords เช่น 抓夹发型教程
2. เลือกจำนวนเป้าหมายต่อแพลตฟอร์ม
3. เปิด Download after finding
4. กด AUTO FIND & DOWNLOAD
5. โปรแกรมจะเปิด Douyin และ REDnote ด้วย browser session ของโปรแกรมเพื่อค้นโดยตรง ส่วน Bilibili ใช้ API สาธารณะ
6. ปุ่ม AUTO จึงใช้วิธีค้นโดยตรงของ REDnote แบบเดียวกับปุ่ม Search REDnote / Xiaohongshu แล้ว ไม่ต้องกดสองปุ่ม
7. Douyin จะลองสร้างคุกกี้สดด้วย Chrome ส่วนตัวแบบซ่อนของโปรแกรมให้อัตโนมัติ ไม่ใช้คุกกี้ส่วนตัวของคุณ
8. ถ้าดาวน์โหลดไม่สำเร็จ ตารางจะแสดงสถานะและ Reason / next step แยกตามสาเหตุ เช่น การเชื่อมต่อขาด, เว็บจำกัดการเข้าถึง, หรือหน้าเว็บไม่มีสตรีมวิดีโอ
9. Target per platform หมายถึงจำนวน URL ใหม่ที่ไม่เคยอยู่ในประวัติ คิว หรือโฟลเดอร์ ไม่ใช่จำนวนผลค้นหาดิบ
10. หากผลบนสุดเคยโหลดแล้ว โปรแกรมจะเลื่อนค้นต่อ; Bilibili ตรวจได้สูงสุด 10 หน้าต่อคำค้น และ Douyin/REDnote เลื่อนจนได้ครบหรือหน้าเว็บไม่มีผลใหม่
11. เมื่อผลใหม่มีไม่พอจริง Log จะแสดงรูปแบบ Platform ใหม่ที่พบ/เป้าหมาย เช่น Bilibili 7/20 แทนการนับคลิปซ้ำให้ครบเป้า

- Needs_Trim ยังไม่ทำ Cover/OCR ต้องเลือกช่วงและตัดให้เรียบร้อยก่อน แล้วจึงทำข้อความและส่งเข้า Ready

- Remove with OCR: ลบข้อความเดิมและใส่แบรนด์ แต่ไม่ใส่หัวข้ออังกฤษ
- Cover with English ยังเลือกได้เมื่อต้องปิดข้อความเดิมทั้งหมด แต่จะมีแผ่นสีเข้มตามตำแหน่งข้อความ
- ช่อง English cover text เปลี่ยนหัวข้อได้ และปุ่ม COVER TEXT + ENGLISH ใช้กับไฟล์ที่เลือกเอง
- Remove with OCR ยังเลือกได้เมื่อพื้นหลังเรียบ แต่ควรตรวจรอยแก้ไขด้วยตา
- ระหว่าง OCR แถบด้านล่างจะแสดงเปอร์เซ็นต์รวมทั้งช่วงตรวจข้อความและช่วงลบข้อความ พร้อมบันทึกทุก 25% ใน Activity log
- ผ่านทุกด่าน: C:\E\HairTutorial\Edited\Ready
- พบข้อความหลงเหลือ ภาพไม่ใช่แนวตั้ง 9:16 มืด เบลอ หรือมีขอบดำ: C:\E\HairTutorial\Edited\Needs_Review
- ไฟล์ต้นฉบับที่ผ่านช่วงเวลาเก็บไว้เสมอ ส่วนไฟล์สำหรับโพสต์เป็นสำเนาใหม่
- Mute edited copies: เปิดไว้เป็นค่าเริ่มต้น สำเนาที่แก้ไขทุกคลิปจะไม่มีเสียง โดยไม่แตะเสียงในต้นฉบับ
- Mute downloaded originals too: เปิดไว้เป็นค่าเริ่มต้น ไฟล์ดาวน์โหลดใหม่จะถูกถอดเสียงแม้ไม่ได้ทำ OCR หรือใส่แบรนด์ การถอดเสียงใช้การคัดลอกภาพเดิมจึงไม่ลดความคมชัด
- การปิดเสียงต้นฉบับมีผลเฉพาะไฟล์ที่ดาวน์โหลดหลังเปิดตัวเลือกนี้ และไม่เปลี่ยนไฟล์เก่าย้อนหลัง
- Dashboard: แสดงจำนวนไฟล์แต่ละสถานะ จำนวนต้นฉบับ คิว และพื้นที่ว่างในไดรฟ์
- Open Ready: เปิดโฟลเดอร์คลิปที่ระบบตรวจผ่านแล้ว

จัดการ Needs Review / Needs Trim หลังแก้ไขไฟล์
- Open Review และ Open Trim เปิดโฟลเดอร์งานที่ต้องแก้โดยตรง
- PROCESS SELECTED MODE → READY: เลือกไฟล์ที่แก้แล้วจาก Needs_Review หรือ Needs_Trim โปรแกรมจะใช้ Automatic text mode ปัจจุบันอีกครั้ง ค่าเริ่มต้น Remove OCR + English Text จะลบข้อความเดิม ใส่หัวข้ออังกฤษ แล้วตรวจซ้ำให้
- คลิปจาก Needs_Trim ต้องตัดให้เหลือไม่เกินค่าช่อง Duration ก่อน หากยังยาวเกิน โปรแกรมจะไม่ส่งเข้า Ready
- เมื่อผ่าน ระบบสร้างภาพปก ย้ายสำเนาที่พร้อมโพสต์เข้า Ready และเก็บไฟล์ก่อนประมวลผลไว้ใน C:\E\HairTutorial\Edited\Reviewed_Sources โดยอัตโนมัติ ไม่ต้องย้ายเอง
- APPROVE FIXED → READY: ใช้เมื่อคุณแก้ข้อความ/ตัดคลิปเสร็จสมบูรณ์แล้วและไม่ต้องการทำ OCR ซ้ำ โปรแกรมจะตรวจความยาว สร้างภาพปก และย้ายเข้า Ready ให้ทันที
- ถ้าการตรวจหลังประมวลผลยังพบข้อความ คลิปใหม่จะอยู่ Needs_Review ต่อและโปรแกรมจะแจ้งให้ตรวจอีกครั้ง

ปุ่มล้างรายการ
- Clear completed: ลบแถวที่ทำงานจบแล้วทุกสถานะออกจากหน้าจอ แต่เก็บไฟล์และประวัติไว้
- Clear all: ล้างคิวทั้งหมด แต่ไม่ลบวิดีโอและไม่ลบประวัติ
- Clear log: ล้างข้อความกิจกรรมและไฟล์ activity.log เท่านั้น

ระบบป้องกันไฟล์ซ้ำ
- โปรแกรมตรวจทั้ง URL ใน download_history.tsv และรหัสวิดีโอที่อยู่ในชื่อไฟล์
- หากเคยดาวน์โหลดแล้ว สถานะจะเป็น already downloaded และจะไม่โหลดซ้ำ
- หลังดาวน์โหลด โปรแกรมตรวจ SHA-256 ของไฟล์ด้วย หากเนื้อหาเหมือนกับไฟล์เดิมทุกไบต์ จะเก็บไฟล์เก่าและลบไฟล์ใหม่ที่ซ้ำ
- บันทึกกิจกรรมถาวรอยู่ที่ C:\E\HairTutorial\activity.log

ควบคุมคิว
- Pause / Resume: พักก่อนเริ่มรายการถัดไป หรือทำงานต่อ
- Stop after current: หยุดคิวหลังรายการที่กำลังทำเสร็จ
- Retry failed: ลองรายการที่ดาวน์โหลดไม่สำเร็จใหม่ โดยเฉพาะ retry needed; โปรแกรมจะพยายามดาวน์โหลด Bilibili ต่อด้วยชิ้นข้อมูลขนาดเล็กเมื่อการเชื่อมต่อขาด
- FULL QUEUE: เปิดตารางขนาดใหญ่ พร้อมคอลัมน์ Reason / next step มีแถบเลื่อนแนวตั้ง/แนวนอน ค้นหาและกรองตามแพลตฟอร์ม ประเภทสินค้า และสถานะได้
- ดับเบิลคลิกแถวในตารางหลักหรือตาราง FULL QUEUE เพื่อเปิด URL
- หน้าต่าง FULL QUEUE เลือกหลายแถวเพื่อ Download, Open หรือ Remove ได้ และสถานะจะรีเฟรชอัตโนมัติ
- Progress bar ด้านล่างแสดงความคืบหน้าของทั้งคิว และมี popup สรุปเมื่อจบ/หยุด
- Parallel platforms: ดาวน์โหลดพร้อมกันได้สูงสุด 3 งาน แต่ไม่เกินหนึ่งงานต่อแพลตฟอร์ม เพื่อป้องกัน browser profile ชนกัน
- หากปิด Parallel platforms โปรแกรมจะดาวน์โหลดทีละไฟล์ตามลำดับคิว
